# Credit Policy Optimizer

A modern, high-performance platform for credit risk modeling, credit policy optimization, and real-time decisioning.

## Stack
- Python 3.11+
- Package management: `uv`
- Data Processing & ML: `polars`, `numpy`, `scipy`, `scikit-learn`, `lightgbm`
- Validation & API: `pydantic v2`, `fastapi`, `uvicorn`
- Code Quality: `ruff`, `mypy` (strict), `pytest`, `pytest-cov`

## Quickstart

```bash
make install
make test
make lint
make run-api
```
